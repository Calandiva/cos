# 포뮬라랩 — 화장품 제조 시뮬레이터

원료를 골라 처방을 짜고, 공정을 돌려서 **실제로 어떤 물건이 나오는지** 계산하는 브라우저 시뮬레이터.
점도·pH·탁도·색상·액적 크기·안정성은 물론, **같은 처방이라도 100 g 비커와 1톤 탱크에서
왜 다른 물건이 나오는지** 까지 물리량으로 보여준다.

서버도, 계정도, 빌드 도구도 필요 없다. `index.html` 하나가 전부다.

---

## 무엇을 하는 도구인가

화장품 처방은 종이 위에서는 맞아떨어져도 탱크에서는 어긋난다.
저울 눈금이 미량 원료를 못 잡고, 물이 마르고, 벽에 남고, 대량 배치는 오래 뜨겁고,
같은 rpm이라도 지름이 다르면 전단이 다르다.

이 도구는 그 어긋남을 전부 계산한다.

| 무엇이 | 왜 달라지는가 |
|---|---|
| **칭량 오차** | 저울 최소눈금·반복정밀도. 0.04% 원료를 100 g 배치에서 재면 오차가 30%가 넘는다 |
| **증발 손실** | 표면적/부피 비 ∝ V<sup>−1/3</sup>. 비커가 탱크보다 20배 잘 마른다 |
| **잔류 손실** | 젖은 면적/부피 ∝ V<sup>−1/3</sup>. 소량 배치의 수율이 낮은 이유 |
| **열이력** | 냉각 시간 ∝ V<sup>1/3</sup>. 1톤은 오래 뜨거워 활성이 깨지고 갈변한다 |
| **냉각 속도** | 라멜라 겔망의 결정 크기를 바꾼다 → 대량이 더 묽다 |
| **전단** | 같은 rpm이라도 호모 지름이 다르면 팁속도가 다르다 |
| **혼합 균질도** | 탱크가 클수록 95% 균질에 오래 걸린다 → 병마다 다른 제품 |

## 원료 213종

**그 원료가 왜 그렇게 쓰이는지**까지 들어 있다. 한글명·INCI·기능·제품명 아무거나로 검색된다.

현재 업계에서 실제로 쓰는 것들을 반영했다. **대세** 배지가 붙은 원료가 그것이다.

## 제품군 17가지

스킨·토너 / 미스트 / 에센스 / 세럼·앰플 / 수분 젤 / 로션 / 크림 / 선크림 /
샴푸 / 컨디셔너·린스 / 클렌징 폼 / 클렌징 오일 / 바디워시 / 바디로션 /
립밤 / 파운데이션 / 헤어 에센스

제품군마다 **출하 규격**(점도·pH·탁도)과 **표준 제조 공정**이 다르다.
제품군을 고르면 규격과 공정 템플릿이 함께 바뀐다.

규격만으로는 대충 만든 것을 걸러내지 못한다. 그래서 제품군마다
**제품이 제품 노릇을 하기 위한 필수 요건**을 따로 건다.

| 제품군 | 필수 요건 |
|---|---|
| 물이 든 모든 제형 | 방부 지수 0.75 이상 · 안정도 하한 |
| 로션 · 크림 · 바디로션 | 유화계 성립(오일에 맞는 유화제) · 평균 액적 4 µm 이하 |
| 선크림 | SPF 30 이상 · UVA-PF 8 이상 (PA+++) |
| 샴푸 · 바디워시 | 세정 계면활성제 하한 · 거품력 하한 |
| 컨디셔너 | 양이온 컨디셔닝제 1.5% 이상 |
| 클렌징 폼 | 비누화 성립 · 거품력 |
| 클렌징 오일 · 헤어 에센스 | 무수(정제수 5% 미만) |
| 립밤 | 무수 · 경도 18~48 |
| 파운데이션 | 착색 안료 0.3% 이상 |

물에 카보머만 풀어 pH 를 맞춘 "젤" 은 규격 숫자는 통과해도
**방부 지수 미달 · 안정도 미달**로 걸린다. 무엇이 왜 모자란지 항목별로 나온다.

여기에 더해 **제형 자체가 성립하는지**를 따로 본다.

| 대충 만든 것 | 결과 |
|---|---|
| 물 + 방부제만 (로션) | 안정 52 · **제형이 없다 (−30)** |
| 물 + 오일, 유화제 없음 | 안정 0 · **유화제 없음 (−35)** |
| 물 + 글리세린 (에센스) | 안정 32 · **제형이 없다 (−30)** |
| 물 + 방부제만 (토너) | 차단 · 보습제 3% 미달 |

토너처럼 원래 묽은 제형에는 "되기가 없다" 고 하지 않는다.
제품군의 점도 하한을 보고 판단한다.

규격·요건 미달은 **무엇이 문제인가** 목록에도 함께 올라온다.
규격은 미달인데 "지적 사항 없음" 이라고 나오는 일은 없다.

| 제형 | 점도가 어디서 나오는가 |
|---|---|
| 젤·세럼 | 카보머 겔 — 중화해야 점도가 나오고, 전해질에 무너진다 |
| 로션·크림 | 라멜라 겔망 — 지방알코올 × 유화제. 냉각 속도에 민감하다 |
| 샴푸·바디워시 | 미셀 모양 — 소금을 넣으면 오르다가 어느 지점을 넘으면 급락한다 |
| 컨디셔너 | 양이온 라멜라 — pH 4 부근에서만 모발에 붙는다 |
| 클렌징 폼 | 그 자리에서 만든 비누 — 지방산 + KOH |
| 립밤·클렌징오일 | 무수. 왁스 배합비가 경도를, 오일 점도의 로그 평균이 흐름을 정한다 |

## 학습 과정 — 17챕터 · 102과제

**학습** 버튼(모바일은 하단 탭)을 누르면 작업 화면 위로 따로 열린다.
제품군마다 6과제씩, 뒤로 갈수록 어려워진다.

| 유형 | 하는 일 |
|---|---|
| **설계** | 빈 처방에서 규격을 맞춘다 |
| **고장 수리** | 분리된 로션, 침전한 샴푸, 알갱이 씹히는 크림을 넘겨받아 고친다 |
| **공정 개선** | 처방은 그대로. 온도·교반·시간·진공만 손봐서 결함을 없앤다 |
| **스케일업** | 랩 처방을 1톤으로 옮겨 규격을 지킨다 |

각 과제에는 **가이드 열어보기**가 있다. 네 가지가 조합되어 나온다.

1. **조건별 실전 조언** — 필수 조건 하나하나를 무엇을 건드려 맞추는가.
   조언은 제형에 맞춰 달라진다. "점도를 올려라" 가 아니라,
   젤이면 카보머와 중화도를, 샴푸면 솔트 커브를, 크림이면 지방알코올을 말해 준다.
2. **제품군 처방 뼈대** — 이 제형이 최소한 무엇으로 이뤄지는지 역할·원료·대략적인 %.
3. **흔히 놓치는 것** — 그 제형에서 실제로 자주 나는 사고.
4. **관련 용어** — 모르는 말은 그 자리에서 뜻을 읽는다.

- 조건은 **제조할 때마다 채점**된다. ○ 가 ✓ 로 바뀌는 걸 보며 진행하면 된다.
- 필수 조건을 모두 채우면 통과(70점), 추가 조건까지 채우면 100점. 등급 S/A/B/C.
- 진행 상황은 브라우저에 저장되지만, 없어도 아무 과제나 바로 시작할 수 있다.

예를 들어 **세럼 4과제 "0.04%를 맞추는 법"** 은 이렇게 돌아간다.
주름개선 고시 원료 아데노신을 100 g 배치에서 재면 오차가 **30.65%** 다.
정밀저울 눈금이 0.01 g인데 목표가 0.04 g이기 때문이다.
배치를 10 kg으로 키우면 오차가 **0.31%** 로 떨어진다. 그걸 직접 확인하는 것이 과제다.

## 조작

작업 화면은 둘뿐이다 — **처방**과 **공정**. 결과는 옆(PC)이나 탭(모바일)에서 함께 보이고,
학습 과제는 별도 화면으로 따로 열린다.

| 하고 싶은 것 | 조작 |
|---|---|
| 원료 담기 | **＋ 원료 추가** → 큰 검색 화면이 열린다. 한글명 · INCI · 기능 · 제품명 아무거나로 찾는다 |
| 양 조절 | 원료 옆 **− 숫자 +**. 휠을 굴리거나 **위아래로 끌어도** 되고, **숫자를 눌러 직접 입력**해도 된다 |
| 많이 넣기 | 표시된 권장량은 상한이 아니라 출발점이다. 1.5% 라고 적혀 있어도 3% 든 10% 든 넣을 수 있다 |
| 원료 설명 | 이름을 누르면 설명 · 물성 · 배수 버튼(½× 1× 2× 4×)이 나온다 |
| 100% 맞추기 | **물로 맞추기** — 정제수가 나머지를 채운다 |
| 카보머 중화 | 처방 아래 **중화 계산기** — 목표 pH에 필요한 양을 계산해 바로 넣는다 |
| 배치 규모 | 상단 배치 버튼 — 큰 다이얼과 프리셋(100 g · 1 kg · 20 kg · 200 kg · 1 t) |
| 공정 고치기 | **공정** 탭에서 온도 · 시간 · 아지 · 호모 · 진공을 같은 방식으로 조절 |
| 제조 | **제조** (또는 `Ctrl+Enter`) — 탱크 안에서 공정이 도는 걸 보여준 뒤 결과가 나온다 |
| 육안 분석 | 결과 화면의 **🔍 육안 분석**. 기울여 보고, 글자에 대보고, 두고 본다 |
| 학습 과제 | 상단 **✦ 학습** (모바일은 하단 탭). 과제를 시작하면 작업 화면 위에 진행 띠가 붙는다 |
| 용어 찾기 | 설정 → **용어집**. 63개 용어를 검색할 수 있다 |
| 배치 간 편차 | 결과 화면의 **편차 ×5** — 같은 조건으로 5배치를 돌려 CV를 본다 |
| 원료 검색 열기 | `/` |

숫자 입력은 전부 같은 방식이다. 작은 값일수록 눈금이 촘촘해진다 —
0.05% 부근에서는 0.001% 씩, 5% 부근에서는 0.1% 씩, 60% 부근에서는 1% 씩 움직인다.

### 제조 연출

**제조**를 누르면 공정이 실제로 도는 걸 보여준다.
수상이 들어차고, 자켓이 붉어지며 온도가 오르고, 유상이 들어가 호모믹서가 돌면 그 자리에서 하얗게 변한다.
진공을 켜면 기포가 사라지고, 70℃를 넘기면 김이 오른다.

**색과 탁도는 흉내가 아니다.** 그 시점까지 투입된 원료만으로 다시 계산한 값이다.
그래서 파운데이션은 안료가 들어가는 순간 살구색이 되고, 로션은 유화되는 순간에만 뿌예진다.

마지막에 완성품이 공개되고 점도 · pH · 탁도 · 안정도가 올라온다.
언제든 **건너뛰기**로 넘길 수 있고, 설정에서 아예 꺼둘 수도 있다.

## 육안 분석

결과 화면의 **🔍 육안 분석**. 실험실에서 시제품을 처음 받으면 하는 일을 그대로 옮겼다.

**기울여 본다.** 액체 표면은 화면 기준으로 수평이 되려 하지만, 되직할수록 천천히 눕고
항복응력이 크면 아예 눕지 않는다. 그래서 기울이면 점도가 눈에 보인다.
슬라이더나 버튼(세움 · 45° · 눕힘 · 뒤집기)으로 조절하고,
휴대폰에서는 **기울기 센서**를 켜면 기기를 기울이는 대로 따라온다.
되직한 제형은 벽에 막이 남고, 잔탄검·히알루론산이 많으면 실이 늘어진다.

| 제형 | 항복응력 | 기울였을 때 |
|---|---|---|
| 토너 | 0 Pa | 물처럼 즉시 쏟아진다 |
| 로션 | 3 Pa | 천천히 기울어 눕는다 |
| 에센스 | 18 Pa | 한참 버티다 천천히 무너진다 |
| 크림 · 젤 | 57 ~ 60 Pa | 거꾸로 들어도 흘러내리지 않는다 |
| 클렌징 폼 | 113 Pa | 떠먹는 되기 |

**글자 위에 대본다.** 배경을 **글자**로 바꾸면 병 뒤에 글자가 놓인다.
탁도가 낮으면 또렷하게 읽히고, 높으면 윤곽만 보이다가, 유백이 되면 전혀 보이지 않는다.
밝은 배경·어두운 배경으로 바꿔 색을 확인할 수도 있다.

**두고 본다.** 보관 기간을 1주 · 1개월 · 3개월 · 45℃ 가속 4주로 바꾸면
그동안 벌어질 일을 계산해 보여준다 — 크리밍 층이 얼마나 두꺼워지는지,
얼마나 누레지는지, 액적이 얼마나 굵어지는지. **흔들기**로 되돌릴 수 있다.

오른쪽에는 관찰 소견이 적힌다. 색상(이름 · 색견본 · L\*a\*b\*), 투명도, 흐름,
입자 크기, 거품력, 경도, 차단력, 굴절률 차, 그리고 규격 판정.

## 결과 읽기

결과 화면은 **한 줄 판정 + 네 개의 큰 숫자**로 시작하고,
자세한 진단(문제 · 규격 · 유화 · 스케일 · 타임라인 · 칭량 기록)은 접혀 있다. 필요할 때 펼치면 된다.

모바일은 하단 탭으로 **처방 · 공정 · 결과 · 학습** 을 오간다.
PC에서는 왼쪽에 작업 화면, 오른쪽에 결과가 함께 보인다.

## 실행 방법

### 1. 로컬 파일로 바로 실행
`index.html` 을 더블클릭하면 된다 (`file://`). 인터넷이 없으면 웹폰트만 시스템 글꼴로 대체된다.

### 2. GitHub Pages
**Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save**

1~2분 뒤 `https://<사용자>.github.io/<저장소>/` 에서 열린다.
(`.nojekyll` 이 있어 Jekyll 전처리를 건너뛴다.)

### 3. Vercel
```bash
npx vercel deploy --prod
```
빌드 명령 없음 / 출력 디렉터리 = 프로젝트 루트. `vercel.json` 이 들어 있다.

### 4. 그 밖의 정적 호스팅
Netlify, S3+CloudFront, Nginx, 사내 웹서버 — `index.html` 하나만 올리면 끝이다.

## 계산 근거

실제 제형 이론을 축약한 모델이다. 절대값은 근사지만,
**무엇을 바꾸면 어느 쪽으로 얼마나 움직이는가** 는 실제와 같다.

**점도** — 네 갈래를 합산한다.
점증제 겔 `η = K·c^n` (pH · 전해질 · 알코올로 보정),
라멜라 겔망 `890·L^2.29` (지방알코올 × 유화제 지지),
계면활성제 미셀 (활성분<sup>1.6</sup> × 솔트 커브),
내상 부피분율 (Krieger–Dougherty, 액적이 작을수록 유효 φ 증가).
전단감점 지수 n을 함께 내어 Brookfield rpm별 겉보기 점도를 계산한다.

**pH** — 산·염기 당량을 세어 Henderson–Hasselbalch로 적정한다.
카보머는 폴리전해질 지수 n ≈ 2를 써서 완만한 중화 곡선을 만들고,
계면활성제·아미노산·추출물의 완충력이 적정 결과를 희석한다.
지방산은 알칼리를 만나면 겉보기 pKa 8.3의 비누가 되어 pH 9~10.5를 만든다.

**액적 크기 d₃₂** — 전단 한계 `5.11·σ^0.6·U_tip^−1.2` 와
유화제 피복 한계 `Γ·6φ/d` 중 큰 값.
계면장력 σ는 유화제/오일 비와 HLB 일치도로 낮아진다.
가용화제가 오일보다 충분히 많으면 전단과 무관하게 10~40 nm 미셀이 자발적으로 생긴다.

**탁도** — 액적의 Mie 산란 `φ × (Δn/0.137)² × s(d)`, 여기서 s(d)는 0.25 µm 부근에서 최대다.
그래서 굴절률이 낮은 실리콘 유화물은 푸르스름하게 맑고, 미네랄오일 유화물은 새하얗다.
무기 입자·석출 결정·혼입 기포를 더한다.

**색상** — 원료 고유색을 색력으로 가중 평균하고,
산란에 의한 백색과 열이력·산화에 의한 갈변을 더해 CIE L\*a\*b\*로 계산한 뒤 sRGB로 변환한다.
비타민C를 80℃에 넣으면 캐러멜색(`#c88e4d`)이, 냉공정으로 넣으면 거의 흰색(`#faf8f2`)이 나온다.

**자외선 차단** — 필터별 1% 당 SPF·UVA-PF 기여를 더한 뒤 세 가지로 깎는다.
광안정성(아보벤존은 안정화제가 없으면 스스로 분해된다), 도포막 균일성(퍼짐 보조제와 액적 크기),
미용해(에틸헥실트라이아존은 82℃, BEMT 는 80℃ 이상에서 녹여야 한다).
UVA-PF 로 PA 등급을 매긴다 — 2 이상 PA+, 4 이상 PA++, 8 이상 PA+++, 16 이상 PA++++.

**거품력** — 계면활성제별 활성분 × 기포력의 합을 오일·실리콘·안료가 깎는다.
지방산은 알칼리를 만나 비누가 된 뒤에야 거품을 낸다.

**방부 지수** — 가진 방부력 ÷ 필요한 방부력.
방부제는 각자의 pH 창에서만 듣고(소듐벤조에이트는 pH 5 이하, 페녹시에탄올은 pH 7 이하),
추출물·발효물·전분은 미생물의 먹이라 필요치를 올리며,
폴리올 25% 이상(낮은 수분활성도)과 알칼리 비누는 내린다.

**경시 변화** — 크리밍 속도 × 시간으로 층 두께를, 산화 지수 × 시간으로 갈변을,
유화제 피복 상태로 액적 성장을 계산한다. 45℃ 가속은 상온의 13배로 본다.

**안정성** — 제형 성립 여부, HLB 정합, 유화제 피복 충분성, Stokes 크리밍 속도와 항복응력에 의한 정지,
상 반전 한계, 전해질 부하, 방부 적합성, 결정 석출, 이온 충돌 침전을 점수로 환산한다.
라멜라 겔망과 미셀 구조도 연속상 점도와 항복응력에 보태져 액적을 붙든다.

**스케일** — 액체를 H = D 원통으로 보고 지름 `D ∝ V^(1/3)`.
증발과 벽면 잔류는 표면적/부피(`∝ V^(−1/3)`)에, 냉각 시간은 `V^(1/3)`에 비례한다.
저울은 목표 중량을 담을 수 있는 가장 정밀한 것이 자동 선택된다.

> 교육·설계 검토용 도구다. 실제 제조·안전성·인허가 판단의 근거로 삼지 말 것.
